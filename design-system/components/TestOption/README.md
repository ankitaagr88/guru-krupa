A diagnostic test the doctor can order, showing whether it has already been run.

**When to use.** In the drawer, as the list of tests available at the current stage. The same row both orders the test and reports on it.

**What the consumer provides.** The test name, its state, and the handler. Names are the machine's, spelled as the machine prints them — `Tono-Pachy (IOP & CCT)`, `Refraction (REF)`.

**States.** Untouched is a plain `surface` row with a `line` border, going `sapphire-wash` on hover. Done carries a `done-tag` in `done-ink` on `done-wash`. In flight carries `done-tag processing` in `gold-deep` on `gold-wash`, which matches the dilation clock's colour language — amber always means *a clock is running*.

**One row, one test.** Don't group tests by machine; staff look for the test, not the device that performs it.

**After a test completes** its values appear as a `ReadingCard` below. The row stays, tagged done, so the list remains a complete account of what was ordered.
